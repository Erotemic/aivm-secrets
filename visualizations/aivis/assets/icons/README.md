# Party and information icons

All pictograms other than `github.svg` were drawn for this visualization and
can be edited freely. `sandbox.svg` denotes the untrusted guest environment,
not a literal OS-security or container-isolation guarantee.

`github.svg` is the GitHub brand silhouette as distributed by the Simple Icons
project (https://github.com/simple-icons/simple-icons, CC0 repository). GitHub
is a trademark of GitHub, Inc.; the mark here identifies the API endpoint and
does not imply endorsement. See the Simple Icons brand/trademark disclaimer.

Both the SVG storyboard and Manim use these same source files. Do not copy the
silhouette directly into render-specific code or add external icon URLs.
